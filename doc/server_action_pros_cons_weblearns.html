Odoo 19 server action — GUI vs module WebLearns
Pros — module approach
Version controlled
Lives in Git — trackable, reviewable, rollback-safe
Auto-deployed on install
No manual GUI clicks on every environment
Full Python power
Import any lib, define methods, use decorators freely
Team-friendly
Shared via module — no per-user manual setup needed
Binding auto-attached
binding_model_id handles Action menu automatically
Better error debugging
Full stack traces in server logs, not vague GUI messages
Cons — GUI Python code block
No import statements
IMPORT_NAME opcode is forbidden — security sandbox
Limited context vars
Only env, records, record, model, log, Warning available
No class definitions
Cannot define functions, classes, or decorators in block
Lost on DB reset
GUI-created actions are not reproducible automatically
Vague error messages
Debugging failures in GUI code block is painful
Not production-safe
Any admin can edit it — no code review, no safety net
Best practice: write logic in model methods, call from server action XML
